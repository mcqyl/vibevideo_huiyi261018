# 把回忆拼好给你

**一支用代码逐帧画出来的手绘动画 MV**

56.2 秒 · 1920×1080 · 30fps · 16:9

`p5.js` × `p5.brush` × `ffmpeg` — 没有一帧是素材拼接，全部由时间 `t` 现场画出来

## 这是什么

这不是剪辑，是**绘制**。

全片 1686 帧，每一帧都是时间 `t` 的纯函数：给定 `t`，程序用毛笔笔触、水彩晕染和会"呼吸"的墨线，从空白纸上画出那一刻的画面。没有关键帧插值，没有素材库，没有后期合成软件。

主角是 Claude 的卡通形象 **Clawd** —— 一块陶土色的小方块，四条短腿、两只竖条眼睛，靠脸和身体演完整场戏。

整片是一条**记忆的弧线**：从碎裂，到被照亮，到重新拼合。

| 8.2 – 15.6 | 直到遇见你，我以为就光明起来<br>眼里都是广袤无垠的大海 | 碎裂处飘起光点，云层向两边分开，一束金光落下。镜头拉开，脚下是夜海，太阳从海面升起，Clawd 站在浅水里，倒影碎在波纹里。 |
| 15.6 – 19.0 | 有你在的日子里不可能被取代 | 她从晨光里走来，拎着装满光点的玻璃罐，每一步踩起水花。他回头、跳起来迎上去，罐子递到两人中间，光点绕他们飞了一圈。 |
| 19.0 – 25.4 | 在最灰暗的日子里你陪着我发呆<br>你让我学会如何拨开阴霾 | 铅灰荒原，乌云压顶，斜雨横扫。她撑伞坐下，然后抬手一挥——把乌云像幕布一样**撕开一道光**。 |

**母题**是**碎片**——开场炸散、中段被收集进罐子、结尾重新拼合成球。首尾是同一个动作的两端。

## 技术

### 一切都画在纸上

```
p5.brush 的 wash  → 平涂色块（角色、道具）
p5.brush 的 fill  → 水彩晕染（天空、远景，带边缘渗化与纸纹）
inkLine()         → 墨线，每秒重绘 12 次，线条会轻微"沸腾"
glow()            → 加色光（唯一不用颜料的地方）
```

颜色**不能随便叠**：p5.brush 按颜料混色，黄色压在蓝色上会变绿，浅色压在深色上会发灰。所以深色场景的光全部走 `glow()` 的加色通道，这是全片贯穿的一条纪律。

### 节奏是量出来的，不是猜的

```
从音频起音点拟合出节拍网格：100 BPM，首拍 0.19 s
→ 所有跳跃、抬手、烟花绽放、笔刷转场都对齐到拍点
```

歌词时间轴来自对音频的逐字转写，再用节拍网格校正。全片 19 句，逐句卡在唱到的位置。

### 每一帧都是纯函数

```js
function shot(t, lt, dur) {   // t 全局时间，lt 镜头内时间，dur 镜头长度
  camBegin(cx, cy, zoom)      // 镜头：世界坐标 → 屏幕
  nightSky(t, {...})          // 背景（整屏重绘）
  clawd(x, y, u, feel('happy', t))   // 角色：情绪自带身体动作
  camEnd()
  if (lt < .3) brushWipe(.5 + lt / .6)  // 转场
}
```

因为是纯函数，帧可以**乱序、并行、断点续渲**。改一个镜头，只需重画它覆盖的那几秒。

### 渲染管线

```
studio.html  ──►  无头 Chrome（--use-angle=d3d11）
                    │  每帧：纸纹 → 笔触 → 墨线 → 加色光
                    │        → 合成字幕层 → 乘上纸纹颗粒
                    ▼
                 out/frames/f00000.jpg … f01685.jpg
                    │
                    ▼
                 ffmpeg ──► H.264 + AAC
```

实测约 **1.0–2.4 秒/帧**（RTX 3070 Ti，4 进程并行），全片约 40 分钟。

## 重新渲染

```bash
cd mv
npm install

# 预览：浏览器打开 studio.html，拖时间轴；或在地址后加 ?t=19.5 直接跳转
# 检查：接触表 / 逐帧条带 / 局部放大
node render.mjs --sheet=0,4,8,12 --cols=4 --w=480 --out=out/check/a.jpg

# 出片
node render.mjs --frames --workers=4 --fps=30     # 逐帧，可断点续渲
node render.mjs --encode --audio=assets/song.m4a --fps=30 --out=out/final.mp4
```

**前置**：Node 18+、Chrome、ffmpeg。字体需自备行楷（`mv/assets/BrushCN.ttf`，或用系统自带华文行楷，改 `karaoke.js` 里的 `KFONT`）。

## 一些踩过的坑

留在这里，省下一个人几小时。

**大面积深色铺色会过曝。** `wash` 叠 `fill` 再叠三层大半径 `glow`，会直接冲到接近纯白。深色场景必须收敛光晕半径与强度。

**背景矩形盖不满会露纸。** 高度写成 `1500` 但画布是 `1080` 且镜头有平移，边缘就露出纸色，形成一条亮带。统一用 `H + 1800`。

**`brushWipe(.5)` 并不真的盖满。** 切镜时会留一道缝。解法是"笔刷 + 全屏深色雾"两层，下一镜头再把雾擦掉。

**字幕是画进帧里的。** 改一句歌词，必须重渲受影响的帧，光重新编码没用。

**变量名不能叫 `push`。** p5 有全局 `push()`，同名局部变量会造成暂时性死区，报错信息还指向别处。

**函数少传一个参数 → NaN → `OffscreenCanvas` 报错。** 报错堆栈指向场景文件，但真正的 NaN 在道具函数里。
